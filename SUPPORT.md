# Getting help

- **Questions** (how do I write a policy, why did it throttle that unit, how do I set up the Splunk sink): ask in [Discussions](https://github.com/jamesconwaydev/sentry-v2/discussions/categories/q-a). Someone else probably has the same question, so asking in public helps them too.
- **Bugs**: [open an issue](https://github.com/jamesconwaydev/sentry-v2/issues/new/choose) and pick the bug report form. If Sentry-v2 acted wrongly or failed to act, use the remediation incident form.
- **Ideas**: the feature request form, or a Discussion if it's still half-formed.
- **Security problems**: not here. See [SECURITY.md](SECURITY.md).

This is a volunteer project, so replies can take a few days.
